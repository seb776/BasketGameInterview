# Game

A tiny basket ball game where you shoot a ball to a moving basket rim and accumulate points during a specified time.
Drag under the ball to "calibrate" direction and strength then release to shoot.

# How to build and run

- WebGL
    - Install WebGL targeting for your unity install 
    - Switch target to "WebGL" then click build
    - Use any webserver locally (via npm, http-server for example)
	- Or host it on a webserver
- Windows
	- Even if it's mainly done for web you should still be able to do a windows build
    - Switch platform to windows
    - Click build
    - Run the executable
